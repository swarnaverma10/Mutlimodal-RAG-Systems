# Mutlimodal-RAG-Systems
Multimodal RAG System for Transformers & Rectifiers (India) Ltd. is an AI-powered semantic search and question-answering system designed using Retrieval-Augmented Generation (RAG). The project retrieves relevant transformer-related information from the TARIL website and generates grounded responses along with matching product images. It combines web scraping, embeddings, FAISS vector search, FastAPI backend, and Streamlit frontend to create an interactive multimodal product assistant. The system is designed to improve technical information retrieval by combining text understanding with image-based contextual responses.
